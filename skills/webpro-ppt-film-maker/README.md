# webpro-ppt-film-maker Skill

Install this folder as an AI coding-agent skill. The important file is `SKILL.md`; keep it inside a folder named `webpro-ppt-film-maker`.

Supported install targets:

- Claude Code: `~/.claude/skills/webpro-ppt-film-maker/SKILL.md`
- opencode project: `.opencode/skills/webpro-ppt-film-maker/SKILL.md`
- opencode global: `~/.config/opencode/skills/webpro-ppt-film-maker/SKILL.md`
- Generic agents: `~/.agents/skills/webpro-ppt-film-maker/SKILL.md`

Restart the agent after installing.
